# LYCEUM NAVIGATOR — NEON EDITION

Демонстраційний вебзастосунок для перегляду схем корпусів і побудови маршрутів.

## Запуск
1. Розпакуйте архів.
2. Відкрийте папку у VS Code.
3. Запустіть `index.html` через Live Server або інший локальний HTTP-сервер.
4. Геолокація працює лише у захищеному контексті: HTTPS або localhost.

## Можливості
- Навігація між приміщеннями на демонстраційній схемі.
- Перемикання корпусів і поверхів.
- Масштабування коліщатком, кнопками та перетягування схеми.
- Пошук приміщень.
- Геолокація пристрою (не визначає кабінет усередині будівлі).
- Налаштування теми та анімації.
- Генератор QR-коду поточної адреси (потрібне підключення до інтернету для бібліотеки QRCode.js).

## Важливо
Схеми, номери кабінетів, проходи та міжповерхові зв'язки є демонстраційними й не підтверджені адміністрацією ліцею. Між корпусами переходи не вигадані. Не використовуйте застосунок для евакуації або як офіційне джерело навігації.

## Структура
- `index.html` — розмітка
- `css/style.css` — оформлення
- `js/data.js` — дані корпусів і приміщень
- `js/engine.js` — пошук і алгоритм Дейкстри
- `js/map.js` — SVG-візуалізація та керування схемою
- `js/app.js` — інтерфейс і події
